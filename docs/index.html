System Architecture & Multi-Channel Pipeline

How jobhunt_opensource discovers, scores, audits, and dispatches job applications autonomously without paying subscription or connect fees.

Stage 1

Playwright & HTTPX Ingestion

Crawls remote postings across AU, UK, and US peak hiring hours. Automatically switches between authenticated session mode and zero-config public mode.

Stage 2

Suitability & Trap Evaluator

Computes 0–100% suitability match based on your verified skills. Scans description for secret codes, mandatory questions, speedtests, and salary caps.

Stage 3

Mutually Exclusive Channel Router

Enforces strict routing: if external email or form exists, apply off-platform and spend exactly 0 connects. Prevents duplicate submissions.

Stage 4

Autonomous Execution Layer

Route A: Direct Email
0 Connects Spent

Dispatches tailored application email with attached PDF resume via SMTP or writes a clean local .eml audit file.

Route C: External Forms
0 Connects Spent

Automates form completion for Google Forms, ClickUp, Typeform, and RecruitCRM using verified ground-truth profile data.

Zero-Connect Guardrail
Cost Prevention

Intercepts standard on-platform listings. Low fit (<60%) jobs are withheld; high-fit jobs are queued for human review.

Stage 5

Persistence & Agent Interfaces

Stores records in SQLite WAL mode. Exposes 8 MCP tools and 5 live resources to AI coding assistants, accompanied by a local web dashboard.

Routing Rules & Cost Guardrails

01
Mutually Exclusive Application Paths

Applications are sent through one channel only: external form, direct email, or on-platform. The engine never double-submits.

02
Zero-Connect Priority Allocation

Employers providing external emails or application forms receive direct submissions at $0 cost, preserving paid connects for exclusive roles.

03
Masked Email Redaction Protection

Listings with masked addresses (e.g. 'Email: ----------') are never emailed blindly. They are flagged for authenticated session unmasking.

04
150–250 Word Length Anchor

Proposals avoid generic cover letter boilerplate. They lead with the employer's code word, cite 2-3 verified achievements with metrics, and anchor remote reliability.

Build Process & Profile Customization

Enforcing a reproducible, step-by-step configuration workflow so new users adapt the automation to their verified experience with zero boilerplate leaks.

1. Copy the Profile Template

Create your personal profile file from the documented example template. Your real profile file (config/profile.yaml) is excluded by .gitignore to protect personal data from accidental git commits.

Bash / Terminal 
# Copy example configuration to active candidate profile
cp config/profile.example.yaml config/profile.yaml

# Alternatively, JSON format is fully supported:
cp config/profile.example.json config/profile.json
Security Rule: Never commit your active config/profile.yaml or .env file. The automated test suite verifies 0 PII leaks before allowing production builds.

2. Edit Verified Career Facts & Logistics

Open config/profile.yaml in your editor and replace placeholder strings with your genuine background. The engine strictly restricts generated cover letters to these verified facts.

config/profile.yaml 
candidate:
  name: "Alex Taylor"
  display_name: "Alex"
  email: "alex.taylor@example.com"
  phone: "+1-555-0144"
  location: "Remote, Worldwide"
  linkedin: "https://linkedin.com/in/alex-taylor"
  portfolio_url: "https://portfolio.example.com"

logistics:
  internet: "300 Mbps Fiber primary with 50 Mbps 5G mobile hotspot backup"
  power: "1500VA UPS backup battery (4 hours continuous runtime)"
  hardware: "Dedicated Workstation with Dual Monitors"
  availability: "Full-time (40 hrs/wk), immediate start across US, UK, or AU timezones"

3. Validate Schema & Audit Placeholders

Run the pre-flight validator tool. It confirms your profile conforms to config/profile.schema.json and verifies zero unedited template tokens remain.

Terminal Verification Command 
python tools/validate_profile.py --config config/profile.yaml
Passing Output (Ready to Deploy)
[VALIDATING] Profile file: config/profile.yaml
[PASS] Schema validation: Passed successfully.
[PASS] Candidate email check: 'alex.taylor@example.com'
[PASS] Placeholder audit: 0 unedited placeholder tokens found.
[SUCCESS] Candidate profile is valid and ready for job matching.
Failing Output (Safety Blocker)
[VALIDATING] Profile file: config/profile.yaml
[FAIL] Unedited placeholders found in active profile:
  - [YOUR FULL NAME]
  - [your.email@example.com]
Remediation: Edit config/profile.yaml with your real verified facts before deploying.

4. Set Optional Environment Credentials

Configure .env if you plan to use direct SMTP email dispatch or authenticated scraping. If left unconfigured, the application runs in public unauthenticated mode and writes draft .eml files.

Bash / Terminal 
# Initialize local environment variables
cp config/.env.example .env

# Edit .env with your SMTP credentials (optional)
# SMTP_HOST=smtp.gmail.com
# SMTP_PORT=587
# SMTP_USER=your.email@gmail.com
# SMTP_PASSWORD=your-app-password

Skill Ecosystem & Standalone CLI Tools

Export the core proposal engine into any agent workflow as a portable, standardized skill package.

/onlinejobs-proposal-generator Standard SKILL.md

A self-contained agent skill with standard YAML frontmatter. Audits job descriptions, surfaces screening traps, enforces candidate ground truth, and writes 150-250 word proposals.

Frontmatter Format: Agents Standard (name, description, version)
Supported Environments: .agents/skills, .cursor/skills, .claude/skills
Ground Truth Anchor: Decoupled config/profile.yaml facts
1-Command Universal Installation (skills.sh)

Use the included POSIX or PowerShell script to install, test, and run the skill in any project workspace:

Bash / macOS / Linux 
# 1. Install skill into your current workspace agent folder
./skills.sh install

# 2. Run automated validation check
./skills.sh test

# 3. Generate a tailored proposal from the command line
./skills.sh run onlinejobs-proposal-generator --jd "Virtual Assistant needed. Put Blueberry in subject..."
Windows PowerShell 
# Install and run on Windows PowerShell
.\skills.ps1 install
.\skills.ps1 test
.\skills.ps1 run onlinejobs-proposal-generator --jd "Virtual Assistant needed. Put Blueberry in subject..."
